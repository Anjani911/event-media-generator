# Brag Plan: Campus Creator AI

## What is this app?
Campus Creator AI currently turns student-club event details and a club style profile into promotional copy for several channels.

## The angle
Show what works today, then preview the next build: from event brief, to copy kit, to a generated poster concept and Google Forms registration concept. The poster and registration scenes are explicitly presented as upcoming concepts, not current capabilities.

## Hook (first 2-3 seconds)
“One event. A whole launch kit.” opens on an event brief and sets up the wider flow.

## Key moments (the middle)
- Ask for the event name, date/time, venue, audience, highlights, and the club voice.
- Generate channel-specific text: poster copy, Instagram, WhatsApp, email, LinkedIn, and taglines.
- Tease the next build: turn the brief into a visual poster, then create a Google Forms registration flow.

## Outro / punchline
“Copy now. Poster + signup next.” clearly distinguishes the current text kit from the planned poster and Google Forms work.

## User flow worth showing
Enter style and event details → generate the currently implemented text kit → preview the planned poster and Google Forms registration concepts.

## Tone
- Preset: app-store
- Creative direction: polished campus-tech product demo with an honest roadmap tease
- Interpretation: smooth interface reveals and readable feature cards; clearly label upcoming poster and registration scenes as concepts.

## Format: landscape — 1920x1080
## Duration: 25 seconds

## Visual identity (from the project)

- Accent: indigo (`#4338ca`)
- Text: zinc-900 (`#18181b`)
- Display font: bold system sans-serif
- Body font: system sans-serif
- Strongest visual element: the Live Prototype's form, two-column layout, and copy result cards.

- Audio-reactive treatment: unavailable because the media-use extraction skill could not be installed in this environment; authored animation is timed to the music cues.

- Restraint rule: do not imply the future poster or form features are live.
